# Raghu Notes Portal — Drive-linked rebuild

Static, GitHub Pages-compatible academic folder directory. No API key, server, or paid hosting required.

## Deploy

1. Create a backup or a new GitHub branch in `Aryan-hpv/raghu-notes-portal`.
2. Upload `index.html`, `ng.css`, `ng.js`, and `data.js` to the repository root on that branch.
3. Preview the branch locally with a simple static web server, e.g. `python -m http.server 8000` and open `http://localhost:8000`.
4. Merge into `main` after reviewing; existing GitHub Pages deployment should update according to your Pages configuration.

## Update Drive links

Edit `data.js`. Each department has a `folder` ID and a `semesters` map of keys `YEAR-SEMESTER` (e.g., `3-2`) to Google Drive folder IDs. Only add real, verified IDs. Use a browser sharing window to ensure students have view permission; listing through an authenticated Drive connection does **not** guarantee public access.

The catalog was checked against the connected Google Drive hierarchy `REC ACADEMICS / AR 23 / 2023-27` on 23 Nov 2026. There are no autogenerated subject/file listings: GitHub Pages cannot securely list a private Drive folder without an API/backend. New files placed inside existing linked semester folders will appear on Google Drive automatically. Newly created semesters require editing `data.js`.

The old site exposed a placeholder Request Notes form; the rebuild intentionally does not show a broken Request link. The existing Contribute and WhatsApp links were retained, and the full-drive link now leads to `REC ACADEMICS`.
